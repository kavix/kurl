# Support

We love helping users and are happy to support the `kurl` community. 

Before asking for help, please make sure you've thoroughly read the documentation on our [Website](https://kavix.github.io/kurl/) or using the internal `kurl --help` flag.

## Getting Help

If you have questions, need help, or want to suggest improvements:

1. **GitHub Issues**: If you have found a bug or have a feature request, please [open an issue](https://github.com/kavix/kurl/issues). We have issue templates set up to guide you on what information we need.
2. **GitHub Discussions**: For general questions, help with using features, or showing off what you built with `kurl`, please use [GitHub Discussions](https://github.com/kavix/kurl/discussions).

## Professional Support

`kurl` is an open-source project maintained by volunteers. There is no official paid support or guaranteed SLA at this time. However, we strive to review all issues and PRs as quickly as possible.

## Security Issues

If you find a security vulnerability, please do NOT open a public issue. Refer to our [Security Policy](SECURITY.md) on how to report it securely.
